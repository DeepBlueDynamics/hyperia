# Release Build Runbook

## CRITICAL: Order matters. Wrong order = wrong sidecar in the installer.

### Step 1 — Bump version (ALL THREE files, same version)

- `package.json` — `"version": "X.Y.Z"`
- `app/package.json` — `"version": "X.Y.Z"`
- `sidecar/Cargo.toml` — `version = "X.Y.Z"`

`target/package.json` is generated by `tsc -b`. Do not edit it directly.

### Step 2 — Close Hyperia

The sidecar build writes to `sidecar/target/release/hyperia-sidecar.exe`.
If Hyperia is open it holds that file and the build fails with "Access is denied."

### Step 3 — Build the Rust sidecar

**Always rebuild the sidecar, even if only TS/HTML changed.**
The installer picks up whatever binary is in `sidecar/target/release/`. If you skip
this step and the binary is stale, the packaged sidecar will have the wrong version
and potentially missing features/fixes.

If `cargo build` fails with "Access is denied" on `hyperia-sidecar.exe`, check whether
`sidecar\target\release\hyperia-sidecar.exe` already exists — if it does, the build
**succeeded**. Cargo is only failing to delete its `.old.exe` backup (Windows Defender
holds it briefly). The new binary is already in place; proceed to Step 4.

If the binary does NOT exist, delete the stale `.old.exe` files and retry:

```bash
del /F "sidecar\target\release\hyperia-sidecar.old.exe"
del /F "sidecar\target\release\hyperia-sidecar.old2.exe"
```

Then build:

```bash
cd sidecar && cargo build --release && cd ..
```

### Step 4 — Build and package

```bash
set AZURE_CLIENT_SECRET=<secret>
yarn run dist
```

Output: `dist/Hyperia-X.Y.Z-x64.exe`

### Step 5 — Verify

```bash
ls -la dist/Hyperia-X.Y.Z*.exe
```

Confirm the file timestamp is fresh and the version in the filename matches.

---

## Common mistakes

| Mistake | Symptom |
|---------|---------|
| Skipped sidecar rebuild | Installer has old sidecar — version mismatch, missing fixes |
| Forgot to bump `app/package.json` | Installer named with old version |
| Hyperia was open during sidecar build | `cargo build` fails: "Access is denied" |
| Bumped version after build started | Installer has wrong version in binary |
